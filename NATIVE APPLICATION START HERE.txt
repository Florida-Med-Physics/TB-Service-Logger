TrueBeam Service Log - native desktop application

WINDOWS
Extract the ZIP and open the single TrueBeam Service Log.exe. No Python installation or companion _internal folder is needed. The UF Proton icon appears on the executable and application window. No HTML file or browser is used for the application interface.
Connect U: and W: before opening the app on the UFHPTI network. The first Windows app hosts the shared database; keep its window/computer running for other staff.
If U: is unavailable, the app opens a local workspace. Select Connection > Connect to shared UFHPTI log to remember the shared TrueBeamApp folder, then restart.

MAC (Apple Silicon)
Extract the ZIP and open TrueBeam Service Log.app. It opens a local workspace unless a shared folder has been selected. Connection > Connect to shared UFHPTI log selects the mounted TrueBeamApp folder; restart to connect. For shared use a Windows host must already be running.
