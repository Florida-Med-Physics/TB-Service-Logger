TrueBeam Service Log - UFHPTI shared application (test release)

Windows: Extract the entire ZIP, then open TrueBeam Service Log.exe inside the extracted folder. Keep its _internal folder beside it.
Connect U: and W: before launching. The first Windows application becomes the host. Keep that application/computer running while other staff use it. Later launches connect through the shared folder automatically. Windows Firewall may require IT to allow private/internal access.

Preset folders:
Service reports: U:\QA\SystemQA\LINAC QA\TrueBeam\Service reports
Screenshots: W:\Varian\Transfer\TDS\H192905\PrintScreen
Excel: U:\QA\SystemQA\LINAC QA\TrueBeam\TrueBeam_Service_Log.xlsx

Shared settings/data: U:\QA\SystemQA\LINAC QA\TrueBeam\TrueBeamApp
Mac: Open the app and select that TrueBeamApp folder on the mounted shared drive. A Windows host must already be running.

The familiar HTML interface opens in your browser. Close the browser without stopping the host. Edits are shared through the running host, with a shared backup after changes.
The Excel data feeds update each minute; an open workbook is never overwritten. Excel external-data refresh must be enabled. Automatic Excel refresh is still undergoing native Excel validation; use the application as the current source of truth during this test.
This build has passed local shared-client tests but has not been tested on the UFHPTI network. The apps are unsigned; local IT policy may require approval.
